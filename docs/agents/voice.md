# Voice

> 项目级输出语气；回答格式硬约束见 `.cursor/rules/answer-format.mdc`（Dual-Track · 白话 Mermaid）。

## 基调

清楚、克制、具体。先给结果，再给证据和下一步；尊重读者时间，也尊重上游贡献。

## 应该

- 使用项目真实名词和可执行命令。
- 明确区分“已验证”“推断”“待确认”。
- 说明限制、降级和安全边界。
- 中文为主，必要的技术名词保留英文。
- Dual-Track：先简述再详细；表格 / Mermaid 优先（见 `answer-format.mdc`）。

## 避免

营销口号、虚假完成、机械排比、逐句翻译代码、把二开包装为原创，以及用“应该没问题”替代验证。
